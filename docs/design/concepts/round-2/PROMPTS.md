## A1 — Тёплая линия

Ближе всего к первому: узкая колонка дат, несколько задач на день, чуть мягче фон и разделители.

Use case: ui-mockup. Generate a NEW refined high fidelity design concept board for Russian student homework app «ДЗ». Input image 1 (A/Линия) is the PRIMARY design reference, about 80% of the direction: clarity, simple lists, readable date hierarchy, blue action accent, useful quiet UI. Input image 2 (B/Пауза) is a SECONDARY reference, about 20%: gentle warmth and comfortable rhythm ONLY, NOT its serif fonts, formal/editorial feeling, beige card stacks or decoration. User wants an authentic small personal tool for students and a few friends, not a corporate product or generic AI-designed dashboard. Refine composition rather than recolor. All text sans-serif, normal and medium weights, heading semibold not heavy black; modest heading size. Blue accent on subtly warm off-white; crisp dark readable text. No slogans, logos, hero, stats, gradients, glass, drop shadows, decorative blobs, neon, thick outlines, dashboard badges, repeated large rounded cards, empty oversize spacing or display serif.
Output: one landscape board with THREE complete tall mobile app screens side by side at equal scale, flat front-on, no phone hardware, tight margins, neutral outer background. First «Задачи», second «Расписание», third «Настройки». Small board caption outside UI using variant name specified below.
