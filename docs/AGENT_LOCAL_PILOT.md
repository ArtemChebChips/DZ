# Умное добавление: локальный пилот 1.23.56

28 сентября 2026. Владелец разрешил реализацию плана и передачу текста записи в Claude.
Используем личный Mac M1 8 ГиБ, Parakeet v3 MLX и Claude Code через Pro.
API-ключи и платный API не подключены. Приложение/данные и ярлык сохранены.

## Реализовано

- В dev-приложении: Настройки → Для бета-тестеров → Текстом или голосом.
- Полные предметы и расписание, якорь, дата/время устройства, часовой пояс,
  сокращения передаются при каждом запросе. Источник — текущие данные приложения;
  отдельной устаревающей копии расписания на сервере нет.
- Несколько черновиков, уточнение с предыдущими карточками, редактирование,
  выбор карточек и единое подтверждение. ВУЦ — заметка с предметом.
- Относительные дни и следующая пара вычисляются кодом с учётом вида, времени и чётности.
  Неоднозначный день недели, неизвестный предмет или срок требуют проверки.
- Parakeet в локальном HTTP-сервисе, повторное использование модели,
  удаление временного аудио; лимит минуты и размера, отказ параллельным запросам.
- Обычное добавление не зависит от сервиса. UI скрыт в production до подключения Mac.

## Проверено

- 45 тестов логики, включая 5 новых для агента; TypeScript и production build.
- Реальный Claude Pro получил разрешённый текст записи с «ВУЗ» и полным расписанием:
  вернул ВУЦ, уточнение «Верно, что речь о ВУЦ?», сохранил тему «по оружию»
  и номера 4.1, 4.2, 4.3, 4.5. Дату пользователь выбирает явно.
- В Chromium на 390 px: реальный запрос, карточка, подтверждение, сохранение в demo.
- Изолированные профили 320/390/1440 px, тёмная тема: без горизонтального
  переполнения, сохранение после reload, двойное нажатие не создало дубликат.
  В этих проверках ответ модели фиксированный, чтобы проверять именно UI/хранилище.
- HTTP ASR с настоящей записью: 3.41 с на первый запрос к сервису, номера сохранены.
  Отдельный benchmark той же записи: 1.74 / 0.85 с, пик MLX 1.98 ГиБ.
- Реальная модель: два предмета с разными сроками разобраны отдельно; исправление
  «по физике не завтра, а послезавтра» сохранило теорвер, номера и страницы.
- Запрос без разрешённого Origin получает 403.
- Снимки и личное аудио в Git не включены. Рабочее хранилище владельца не использовалось.

## Остаётся, не выдавать за готовое

1. Защищённая связь iPhone/Pages с MacBook (HTTPS и авторизация). Локальный
   loopback нельзя использовать как адрес сервиса для телефона.
2. Реальная запись через микрофон и Safari/standalone, ошибки разрешений, тишина,
   шум; пока проверен аудиофайл через реальный сервис, а не запись браузером.
3. Приёмка локального интерфейса владельцем и обычная кнопка быстрого добавления.
4. Расширенная приёмка сложных фраз; базовый пакет и одно уточнение уже проверены.
5. Подтверждённые каникулы/переносы и весенний семестр — данных пока нет.
   Контекст явно помечает исключения неизвестными.
6. Уточнение точного занятия при ручной смене предмета/даты: сейчас привязка
   сбрасывается, сохранённый срок остаётся фиксированным.
