# ДЗ — трекер домашних заданий

PWA для студента МГТУ им. Баумана: расписание с числителем и знаменателем, домашние
задания по дням, список по дедлайнам. Пользуются владелец и пара друзей, живёт на iPhone
с домашнего экрана.

- Репозиторий: https://github.com/ArtemChebChips/DZ, ветка `main`
- Сайт: https://artemchebchips.github.io/DZ/

## Как работать с владельцем

- Общаться по-русски, коротко и по делу.
- **Код максимально простой.** Красиво и качественно, но без усложнений — иначе
  появляются баги, которые трудно найти.
- **Каждое изменение публикуется:** поднять `version` в `package.json` → `npm run build`
  → коммит → `git push`. GitHub Actions сам выкладывает сайт (обычно ~40 с, бывает до 6 мин).
- **Всегда называть номер версии.** Владелец сверяет его в Настройках (строка сверху).
- Перед публикацией проверять в браузере в мобильном размере 375×812.
- Владелец тестирует на iPhone. Если обновление не приехало — полностью закрыть
  приложение или нажать «Обновить приложение» в Настройках.
- Варианты дизайна показывать картинками; подпись ставить **над** картинкой.

## Ветка Codex — не трогать

`codex/redesign` — параллельная версия от другого ИИ. Общий workflow
`.github/workflows/deploy.yml` публикует обе: наша на `/DZ/`, их на `/DZ/codex/`.
Если сборка упала без причины с нашей стороны — смотреть шаги Codex (их `npm test`).

## Стек и команды

React 19 · Vite 8 · TypeScript · Tailwind 4 · vite-plugin-pwa · npm.
Роутинг на хеше, сервера нет.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # включает проверку типов tsc
```

Тестов нет — единственная автоматическая проверка это `tsc` в сборке.

## Главные правила приложения

- **Числитель/знаменатель** считаются от якоря: неделя с понедельника
  `2026-08-31` — числитель (`ANCHOR_MONDAY`). Номер календарной недели не используется.
- **Даты** — строки `YYYY-MM-DD`, разбираются вручную. Не использовать `new Date('YYYY-MM-DD')`:
  он парсит в UTC и сдвигает день.
- **У каждой пары своё время** (`start`/`end`), общей сетки звонков нет. Преподаватель
  хранится у пары, а не у предмета.
- **Цвет = вид аттестации:** экзамен — красный, распределённый экзамен — оранжевый,
  зачёт — синий, без аттестации — серый. Пары типа «лаба» всегда зелёные.
- **Задание:** предмет (можно без него) + текст + дата сдачи `due`. Кнопка «Следующая
  пара» ищет занятие с учётом чётности (`nextLessonDates`).
- **«Актуальная неделя»** — текущая неделя; в воскресенье ею считается следующая.

## Экраны

- **Задачи.** Блоки «Просрочено / Актуальная неделя / Следующая неделя / Больше недели»,
  сворачиваются. Слева крупное число дня, справа плашки задач. Свайп вправо — выполнено,
  влево — кнопка «Удалить», долгое нажатие — правка текста на месте.
- **День.** Вкладка всегда открывает сегодня, свайп листает дни. Высота пары
  пропорциональна длительности. В шапке слева бейдж «Ч»/«З», справа кнопка календаря;
  в пределах актуальной недели заголовок — день недели, дальше — число.
- **Редактор задания.** Предметы сгруппированы по виду аттестации, есть «Без предмета»,
  свой календарь подсвечивает дни, когда есть пара.
- **Настройки.** Ночная тема, «Режим сдвгшника», оставлять выполненные, вибрация
  (только Android), расписание и предметы, резервная копия JSON, обновление приложения,
  демо-задания, удаление всех заданий.

## Данные

Всё в `localStorage` на устройстве: `dz:data` (версия формата 3), `dz:theme`,
`dz:collapsed`, `dz:device`. Синхронизации между устройствами нет. Перенос — выгрузка
и загрузка JSON в Настройках.

## Не трогать без веской причины — выстрадано на iPhone

- `index.html`: viewport **без** `viewport-fit=cover`, а
  `apple-mobile-web-app-status-bar-style` = `black-translucent`. Только в этом сочетании
  на iPhone нет полосы снизу. Попытки менять это много раз ломали низ экрана.
- Нижняя панель — плавающий пузырь поверх списка. Отступ `.safe-bottom { padding-bottom: 16px }`
  подобран вручную; не возвращать `env(safe-area-inset-bottom)`.
- `body` зафиксирован, скроллится только `main` — иначе панель уплывает при прокрутке.
- Стили по имени элемента — только внутри `@layer base`, иначе перебивают утилиты Tailwind.
- Вибрация на iPhone не работает в принципе (в Safari нет Vibration API) — это не баг.
