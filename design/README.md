# Ранние эксперименты вёрстки

Эти прототипы начаты до уточнения владельца о работе через ImageGen. Они сохранены для истории и возможного повторного использования кода, но не являются утверждённым дизайном или реализацией новых картинок.

Текущий порядок и статус — в `../docs/REBUILD_PLAN.md`. Сначала выбираем и уточняем изображения из `../docs/design/concepts/`, затем верстаем выбранное направление.

Локальное демо: `npm run dev:design`. Проверка сборки: `npm run build:design`. Данные только в памяти; рабочее хранилище и PWA не подключены. Обозначения A/B/C внутри демо относятся к старым экспериментам.
