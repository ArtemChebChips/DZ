# Варианты иконки расписания

По просьбе владельца: четыре векторных варианта в текущей нижней панели, на светлом и тёмном фоне. A — часы; B — сетка недели; C — лента занятий; D — пары. Рекомендуется B: читаемая таблица, отличается от верхнего календаря. Текущая иконка приложения сохраняется до выбора владельца. SVG выполнен кодом в существующем стиле stroke 1.8, без растровых ассетов.
