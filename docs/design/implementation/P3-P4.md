# P3–P4 — предметы и задания у пар

Версия 1.23.5, 22 сентября 2026.

- Свой список предметов в том же окне редактора, выделение выбранного, возврат фокуса, сохранение текста и даты. Названия сокращены по просьбе владельца, ID сохранены.
- Семинары помечены синим, лабы зелёным; цветные точки видны и у выбранного дня. Лекции не предлагаются для нового ДЗ.
- Конкретное время выбирается явно при нескольких парах. При переносе на следующий день лаб сохраняется выбранное время, если эта пара существует.
- Задание показано внутри нужной пары. Старые однозначные записи сопоставляются с семинаром/лабой; неоднозначные остаются на дате без привязки. Исчезнувшая явная связь не подменяется другой. Старые записи к лекциям доступны.
- По уточнению владельца убран оставшийся нижний padding панели (12→0 px), верхний уменьшен 9→5 px. В режиме ярлыка оболочка занимает 100% окна вместо динамической высоты Safari. Календарь по-прежнему открывается снизу. Подтверждение нижнего края на реальном iPhone ещё требуется.

## Проверки

Сборка и 11 тестов прошли. Браузер Edge: 375/390/430/844/1440 px, обе темы. Проверены свой список, отмена, выделение, сохранение текста, цветные маркеры, выбор второй лабы, выполнение в паре, отсутствие создания ДЗ у лекций. В отдельной базе проверено сохранение семинара и срока после перезапуска. Дополнительно проверен перенос второй лабы на следующую дату с сохранением её времени. Снимки просмотрены; временные файлы — `.cache.local/p34/` и `.cache.local/p34-check.cjs`.

Эмуляция не заменяет iPhone. Пустая область ниже подписей уточнена владельцем; восстановление полного окна в standalone — проверяемая поправка, а не доказанная диагностика конкретной версии iOS.
