# Покрытие актуального приложения

База: `c218703`, 232 отслеживаемых файла. Перечень заполняется с раздельными статусами «прочитан», «связи проверены», «поведение проверено», «исторический материал/артефакт». PNG-концепции, отчёты, lockfile и сгенерированные кеши не считаются исходным runtime-кодом.

## Карта

`design/main.tsx` → storage/data/use-today → задачи/группы/история/привязки → components/schedule-day → navigation/gestures/motion/CSS.

`vite.design.config.ts` → design/index.html/public → собственный worker → общий assemble-pages в корень и /next.

`src/data/schedule.ts`, `src/lib/dates.ts`, `src/lib/week.ts`, `src/types.ts` — общая логика; остальные src — прежнее приложение.

smart-input frontend → dev proxy → voice-local Python → ASR/Claude (изолированный локальный пилот, без реальных внешних запросов в аудите).

## Пофайловый учёт

Полный машинный журнал: `audit/coverage.json`. В нём **232 файла исходной базы** и новые проверочные файлы, каждый с ролью, статусом, доказательством и SHA-256. Исходники текущего `design/`, его пять общих модулей и инструменты/локальный пилот прочитаны целиком. 34 файла design включают HTML, worker и manifest; это не 232 runtime-файла. PNG проверены по заголовкам/размерам и включению в оболочку. Исторические концепции/отчёты перечислены, их полное прочтение и повторная приёмка не заявляются.

Статусы разделены: `runtime-reviewed`, `shared-runtime-reviewed`, `pilot-reviewed/read-only`, `tooling-reviewed`, `test-reviewed`, `context-read`, `runtime-asset-validated`, `legacy/historical-inventoried`, `excluded-personal`, `generated-removed`. Проверки и аппаратные ограничения находятся в профильных журналах.

```sh
node scripts/check-audit-coverage.mjs
```

Проверка требует записи для каждого текущего design-файла и его относительных импортов; затем сравнивает хеши полностью просмотренных файлов. Новое/изменённое содержимое должно снова пройти просмотр и связанные проверки. Автоматический скрипт **не присваивает** статус «изучен» неизвестному коду.

Полностью прочитанный свежий обзор — `docs/PROJECT_OVERVIEW.md`; полностью прочитан `docs/IPHONE_FIX_PLAN.md`. Остальные прежние планы используются как исторический контекст по мере необходимости, их прочтение не приписывается этой сессии. Личные материалы исключены по AGENTS; они не изменялись.

Все данные браузерных сценариев синтетические. Mock-пилот не доказывает качество модели или микрофона. Набор сценариев покрывает связи и границы, перечисленные в `TESTS.md`, но не каждое возможное устройство/сочетание действий.
