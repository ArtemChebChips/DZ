# Первая подборка концепций

19 сентября 2026. Режим: встроенный ImageGen, навык imagegen. Изображения для выбора направления, не утверждённая вёрстка. Каждый вариант генерируется отдельным вызовом. Дополнительные пять вариаций — после обратной связи владельца.

## A — Линия

Use case: ui-mockup. Create a high fidelity design concept image for a small Russian student homework planner called «ДЗ», for personal use and a few friends. This is a visual exploration before implementation. Landscape board containing exactly three full mobile app screens side by side, front-facing flat screenshots, no device mockup, no perspective, no hands. Screens occupy nearly the whole image. Screen 1: «Задачи», screen 2: «Расписание», screen 3: «Настройки». Consistent bottom navigation on each: «Задачи», «Расписание», «Настройки» with corresponding active state. Beautiful careful typography, highly readable Russian text, generous touch targets, strong text contrast. Primary function is immediately seeing homework deadlines; dates must be large and unmistakable, separate from long titles. Same sample content across concepts: Monday September 21, 2026; «Сегодня», «21 сентября», «Физика», «Решить задачи 3–7»; tomorrow «22 сентября», «Английский язык», «Выучить слова»; later «24 сентября», «Математика», «Подготовиться к семинару». Task completion circles and a clear add action. Schedule screen compact September 2026 calendar (September 1 Tuesday, 21 Monday) above selected day's agenda: «09:00–10:35», «Физика», «Лекция», «Ауд. 302» then «10:45–12:20», «Математика», «Семинар». Show «Числитель» week indicator discreetly. Settings screen practical grouped rows «Оформление», «Предметы», «Расписание», «Резервная копия», «О приложении» with useful controls and chevrons, no login or profile hero. All screens visually coherent yet composed for their purpose. Avoid business CRM dashboards, charts, metrics, illustrations, fake browser chrome, gratuitous gradients, tiny gray text, huge empty spaces. Do not add features unrelated to homework.
Concept A «Линия»: precise restrained contemporary utility. Bright neutral background, crisp near-black grotesk type, a single deep blue action accent. Main task screen uses an oversized date rail at left and compact task rows at right, fine separators, very few enclosing cards. Calm disciplined layout, information is effortlessly scannable. Calendar and settings carry the same fine editorial grid. A small caption above the board reads «A / Линия».
