# Нижняя навигация в iOS 27 — 1.23.20

## Воспроизведение

26 сентября 2026, Xcode 27, iOS 27.0, iPhone 17 Simulator.
Локальный адрес `http://127.0.0.1:4176/`, отдельное тестовое хранилище.
В Safari использовался `?demo=1&fixture=stress`; после установки с домашнего
экрана манифест открывает корень адреса, поэтому в PWA использованы локальные
примеры из панели бета-тестера. Данные опубликованного приложения не открывались.

1. Открыть приложение в Safari, добавить на домашний экран с включённым
   «Открыть как веб-приложение».
2. Запустить ярлык. Оба признака подтверждены: `navigator.standalone === true`
   и `matchMedia('(display-mode: standalone)').matches === true`.
3. В версии 1.23.19 подписи нижних вкладок обрезаны: [до](before.png).

В портрете экран имеет размер 402×874 CSS px, доступный viewport — 402×812.
`100lvh` и `100vh` равны 874, а `100dvh` — 812. Отдельное правило standalone
принудительно растягивало контейнер до 874: навигация заканчивалась на y=874,
на 62 px ниже доступной области.

## Исправление

Удалено переопределение standalone с `100lvh`/`max(...)`. Общее правило
`height: 100%; height: 100dvh` теперь применяется и в PWA. Системные отступы,
композиция, прокручиваемый контент и логика данных не изменены.
После исправления нижняя граница навигации равна 812: [после](after.png).
Диагностический скрипт измерял геометрию только на временном локальном сервере;
в приложение и сборку он не включён.

## Проверки

- iPhone 17, iOS 27: в Safari проверены загрузка демоданных и нижняя панель.
  Основные сценарии выполнены в настоящем standalone: три вкладки, светлая и
  тёмная темы, 24 примера и прокрутка до конца (2323 + 633 = 2956 px), календарь
  и выбор дня, редакторы задания/заметки, открытие и закрытие экранной клавиатуры.
  [Кнопка редактора над клавиатурой](keyboard.png), [поворот](landscape.png).
  После закрытия клавиатуры и возврата с домашнего экрана навигация доступна.
  Горизонтального переполнения в измеренных состояниях нет.
- iPhone 13 и iPhone 16 Pro Max: профили созданы на iOS 27.0, но первый запуск не дал доступного рабочего экрана,
  Safari возвращал тайм-аут. После штатного перезапуска `simctl bootstatus`
  сообщил `Data Migration Failed`. Ошибка повторилась на обеих моделях; проверка приложения на них не состоялась.
  Новые версии iOS не скачивались; устройства запускались по очереди.
- Chromium: 390×844 и 1440×900, вкладки, обе темы, редакторы и сохранение
  тестовых задания и заметки; горизонтального переполнения нет.
- `npm run build:design` — успешно; `npm run test:next` — 17/17.

Полноценный ввод текста средствами управления Simulator не подтверждён:
проверены геометрия редактора и положение кнопки при настоящей экранной
клавиатуре; сохранение с вводом текста проверено отдельно в Chromium.
Физические iPhone, iOS 26 и Android не проверялись.

## Ограничения завершения

После переключения профилей повторный запуск iPhone 17 также остался на
логотипе Apple, хотя `bootstatus` сообщил `Finished`; открытие Safari вернуло
тайм-аут. Это не отменяет сохранённые результаты первой сессии, но повторная
проверка после перезапуска не состоялась. Среду Simulator нужно восстановить.

Push заблокирован отсутствием авторизации GitHub на Mac:
`fatal: could not read Username for 'https://github.com': Device not configured`.
Версия 1.23.20 подготовлена локально; публикация этим изменением не выполнена.
