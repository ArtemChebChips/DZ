# Проверки 1.23.54

После исправления единиц времени в 1.23.53 обычный свайп стал применять прежнюю формулу с фактическими 320/550 мс: доведение могло занимать до 480/825 мс. В прежней опубликованной версии из-за ошибки единиц срабатывал минимум 180 мс. Теперь доведение явно ограничено 100–180 мс, reduced motion сохранён. Слежение за пальцем и отмена жеста не изменены.

Календарь: убрана задержка `usePressAction` перед переключением; движение занимает 140/220/260 мс. Кнопки на время движения остаются disabled, но не теряют яркость. Нажатая кнопка сохраняет собственный плавный отклик. Убраны margin/padding viewport по 6 px: граница обрезки совпадает с шириной ленты, уходящий месяц не остаётся снаружи. Анимация высоты при разном числе недель сохранена.

## Готовая сборка, а не dev

- TypeScript/Vite и 40 тестов прошли; тест свайпа проверяет верхнюю границу времени и reduced motion.
- Chromium/WebKit: ширины 320/390/430/1440, все три скорости на 390. Начальная сетка видима, движение содержит промежуточные кадры, длительность не больше 260 мс. Во всех кадрах opacity обеих стрелок и «Текущего месяца» равна 1. Обрезка без бокового запаса, возврат месяца оставляет окно открытым; reduced motion без движения.
- Chromium с настоящими событиями touch через CDP: пять последовательных свайпов при «Плавно», каждый следующий жест через 220 мс после отпускания. Все пять дней переключились; доведение не осталось активным.
- Повторены восемь зон начала свайпа, разворот/отмена, сохранение прокрутки, отсутствие ложных кликов и работа кнопки задания после жеста.

## iPhone 17, iOS 27 Simulator / Device Hub

На локальной установленной копии смена светлой темы на тёмную перезагрузила приложение и обновила системную полосу. Проверены первое открытие календаря, сентябрь → октябрь → ноябрь (6 строк) → «Текущий месяц»: календарь остаётся открыт, выбранное 27 сентября сохраняется. Быстрый переход заканчивается до получения первого снимка, поэтому промежуточные кадры и численные длительности подтверждены браузерными проверками, не этой серией снимков. Через Device Hub также выполнен горизонтальный жест: расписание переключилось с 27 на 28 сентября без открытия задания. Серия быстрых свайпов измерена в CDP, не на iOS. Физический iPhone не проверялся.

Окна редактора, возврат «Сегодня», тумблеры, данные и иконка не изменены. Личные файлы исключены из коммита.
