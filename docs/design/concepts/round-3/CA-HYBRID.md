# C + A — уточнённое направление

## Финальный выбор владельца

Владелец одобрил C + A с последним изменением: полностью убрать верхнюю надпись «Расписание» и освободить её строку. Название остаётся только в нижней навигации. При реализации сохранить safe area сверху. R1 завершён выбором; дальнейшая вёрстка — по R3.

![Финальный вариант без верхней подписи](ca-final.png)

Финал создан встроенным ImageGen из ca-hybrid.png по ca-final.prompt.txt; просмотрены оба состояния, удаление верхней строки и сохранение нижней навигации. Ниже оставлен предыдущий вариант для истории.

Владелец выбрал основу C: календарь и возврат «Сегодня» справа в одной строке. Из A переносим более крупный размер дня и даты, жирный день недели и более лёгкое начертание даты. Название раздела остаётся вторичным. Стрелок нет.

![C + A](ca-hybrid.png)

Создано встроенным ImageGen по ca-hybrid.prompt.txt. Референсы: c-compact.png (основа) и a-day-first.png (типографика). Слева 24 сентября, справа 25 сентября. Результат просмотрен: правая группа сохранена, день выделен жирным, дата увеличена; отдельного возврата на текущем дне нет. Это концепция для R1, код и версия приложения не изменены. При вёрстке R3 проверить длинные месяцы и дни на 375/390/430 px: иллюстрация не заменяет проверку размещения реального текста.
