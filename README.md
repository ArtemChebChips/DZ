# ДЗ

Трекер домашних заданий для вуза с двухнедельным расписанием (числитель / знаменатель).

Работает как PWA: ставится на домашний экран телефона, открывается без интернета,
данные хранятся только на устройстве.

## Зачем

Часть предметов идёт раз в две недели, поэтому «сдать к следующей паре» — это то через
неделю, то через две. Приложение считает это само: когда записываешь задание с плашки
пары, дедлайн подставляется на дату **следующего занятия по этому предмету**.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 — удобнее в мобильном виде (в DevTools 375×812).

Сборка:

```bash
npm run build
```

## Экраны

- **Задачи** — блоки недель (просрочено → эта неделя → следующая неделя → больше недели),
  внутри блока строки дней, внутри дня сами задания. В воскресенье «этой неделей»
  считается уже та, что начинается в понедельник.
- **Календарь** — месяц, слева у каждой недели метка Ч/З, в днях точки цветов предметов,
  по которым что-то сдавать.
- **День** — пары этого дня из расписания с учётом чётности; задания висят на плашке
  своей пары, остальные — в блоке «Сдать в этот день».
- **Настройки** — оформление, чётность недели, расписание, предметы, резервная копия.

## Темы

Три штуки, переключаются тумблерами в настройках:

- **Тихий** — по умолчанию, светлый серо-голубой;
- **Ночная тема** (`data-theme="night"`) — спокойный тёмный;
- **Режим сдвгшника** (`data-theme="adhd"`) — кислотный жёлтый с чёрными обводками.

Токены Tailwind в [src/index.css](src/index.css) смотрят на CSS-переменные, а те
переопределяются по `data-theme` на `<html>`, поэтому разметка у всех тем общая.
Цвета предметов тоже переменные (`--subj-*`): в ночной теме они светлее, иначе бы утонули.
Состояние темы — в [src/lib/theme.ts](src/lib/theme.ts).

## Как считается чётность

В настройках хранится **якорь** — понедельник недели, которая точно числитель
(`settings.anchorMonday`). Чётность любой даты = чётность числа недель от якоря.

Если приложение показывает не ту неделю, достаточно на неделе-числителе нажать
«Текущая неделя — числитель» — сместится всё разом. Каникулы и переносы это переживает.

Вся логика — в [src/lib/week.ts](src/lib/week.ts), экраны её не дублируют.

## Структура

```
src/
  types.ts              модель данных
  store.ts              состояние + localStorage + экспорт/импорт
  lib/week.ts           чётность недели, пары на дату, дата следующего занятия
  lib/dates.ts          даты как строки 'YYYY-MM-DD', русские форматы
  lib/router.ts         роутинг на хеше
  lib/palette.ts        ключи цветов предметов
  lib/theme.ts          выбранная тема
  screens/              Задачи, Календарь, День, Настройки, Расписание, Предметы
  components/           карточки, редактор задания, общий UI
  data/schedule.ts      расписание (настоящее, снято с портала)
```

## Данные

Всё лежит в `localStorage` под ключом `dz:data`, на сервер ничего не уходит.
В настройках есть выгрузка и загрузка JSON — это и бэкап, и способ перенести
расписание на другое устройство.

У записей есть `id` и `updatedAt`, а у заданий ещё `authorId` — задел под общую базу
с одногруппниками, если позже захочется синхронизации.

## Деплой

GitHub Pages (репозиторий `<user>/<repo>`):

```bash
BASE_PATH=/<repo>/ npm run build
```

Содержимое `dist/` опубликовать на Pages. На айфоне открыть ссылку в Safari →
«Поделиться» → «На экран Домой».

Для Vercel или корня домена переменная `BASE_PATH` не нужна.
