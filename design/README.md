# ДЗ — Лист

Кликабельный макет выбранного владельцем варианта A4. Версия 1.22.0.

- `npm run dev:design` — локальный запуск на http://127.0.0.1:4175/.
- `npm run build:design` — проверка TypeScript и сборка в `dist-design/`.
- Если порт занят статическим превью, его сервер нужно сначала остановить либо передать Vite другой порт.

Три вкладки, редактор, темы и операции с заданиями на данных в памяти. Исходное расписание импортируется из `src/data/schedule.ts`, вычисления дат — из существующих функций. Рабочее хранилище, PWA, импорт и экспорт не подключены. Демонстрационная дата — 21 сентября 2026, изменения сбрасываются после перезагрузки.

`main.tsx` — вкладки и состояние; `components.tsx` — календарь, диалог и редактор; `data.ts` — примеры; `style.css` — оформление A4. Ранние три прототипа доступны в истории Git (коммит 10732eb).

Параметры превью: `?screen=schedule`, `?screen=settings&theme=dark`, `?fixture=stress`, `?fixture=empty`. Примеры также переключаются через раскрываемый блок «Демонстрационный макет» внизу страницы.
