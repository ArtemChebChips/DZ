# P1 — отступы и положение навигации

21 сентября 2026, версия 1.23.2, ветка `codex/rebuild`. Реализован только P1; календарь, названия предметов и правила заданий остаются для следующих этапов.

## Диагностика

В исходной версии на 390×844 пустые задачи и настройки имели высоту документа 844 px, расписание — 1174 px. Прокручивался весь документ; навигация была фиксированной поверх него. В браузере Edge координата панели оставалась 768 px: скачок, описанный на iPhone, здесь не воспроизведён. Подтверждены отсутствие верхнего safe area и независимые отступы содержимого/фиксированной панели.

## Изменения

- Общая оболочка — сетка высотой `100dvh`, с резервным `height: 100%`. Основная область прокручивается отдельно, навигация располагается в собственной строке. На компьютере сохранена боковая навигация.
- Верхняя область получает безопасный отступ плюс 24 px. Боковые отступы учитывают горизонтальное положение. Нижний отступ навигации — максимум из обычных 10 px и безопасной области, без сложения этих величин. Искусственный запас 112 px под содержимым удалён.
- Переключение вкладки сбрасывает прокрутку основной области, а не окна браузера.
- Диалог учитывает высоту и смещение видимой области. При её изменении активное поле при необходимости прокручивается между шапкой и кнопкой сохранения. Обработчики снимаются при закрытии. Поведение API сверено с [MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport).

## Выполненные проверки

- `npm run build:design` — успешно, TypeScript и сборка Vite.
- `npm run test:next` — 5 из 5, сохранность записей и ошибки хранения.
- Playwright / Edge (Chromium): 30 сочетаний — размеры 375×812, 390×844, 430×932, 844×390, 1440×900; две темы; пустой, обычный и длинный списки.
- Во всех сочетаниях: переходы между тремя вкладками, прокрутка до конца, стабильная координата навигации, отсутствие прокрутки документа и горизонтального переполнения. Последняя строка доступна над панелью.
- Редактор: ввод, уменьшение высоты окна до 420 px, доступность сохранения, возврат высоты, сохранение записи. Ошибок JavaScript не было.
- Отдельная имитация безопасных отступов 59/34 px и асимметричного бокового отступа в горизонтальном положении. Отдельная имитация VisualViewport высотой 420 px со смещением 80 px: поле целиком между шапкой и нижними кнопками, ввод и сохранение работают, после закрытия навигация возвращается на место.
- Просмотрены снимки светлого списка, тёмных настроек, настольного расписания, горизонтального редактора и редактора с имитацией клавиатуры. Снимки и временный проверочный сценарий находятся в игнорируемой `.cache.local/p1/`.

Уменьшение окна, подставленные safe area и VisualViewport — проверки геометрии в Chromium. Это не запуск iOS, не реальная экранная клавиатура и не подтверждение исправления на физическом iPhone.

## Проверка владельцем на iPhone

Открыть старый ярлык с интернетом; в настройках должна быть версия 1.23.2. Переключить задачи → расписание → настройки → задачи, прокрутить длинный экран, открыть редактор и клавиатуру, закрыть их. Проверить верхний заголовок и положение панели; повторить в Safari и после поворота экрана. Если осталась ошибка, записать режим запуска и шаги; выпускать её отдельное исправление до следующей функции.
