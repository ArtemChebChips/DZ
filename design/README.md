# Новая версия ДЗ для iPhone

Версия 1.23.1. Дизайн выбран по варианту A4 «Лист» — это название концепции, не формат бумаги.

Публикация: https://artemchebchips.github.io/DZ/ . Каждый push в codex/rebuild запускает сборку всех версий и публикацию Pages.

- `npm run dev:design` — локальный сервер (только на компьютере).
- `npm run build:design` — сборка нового приложения в dist-design.
- `npm run test:next` — проверки хранения, валидации и ошибок доступа.

Обычный запуск использует текущую дату и сохраняет задания, тему и свёрнутые дни в `dz-next:v1`. Старые ключи `dz:*` не читаются и не меняются. Можно скачать JSON-копию. Импорт и редактирование расписания/предметов ещё не подключены. Manifest поддерживает ярлык iPhone, офлайн-режим пока не реализован.

Для примеров: `?demo=1`, `?demo=1&fixture=stress`, `?demo=1&fixture=empty`. Демо работает только в памяти, дата — 21 сентября 2026. Параметры `screen=schedule` и `screen=settings` открывают соответствующую вкладку.

Старый ярлык iPhone открывает новую версию в корне. `/next/` остаётся дополнительным адресом, прежний интерфейс — `/legacy/`. Worker заменяет старый app-shell сетевым режимом, без удаления данных.
