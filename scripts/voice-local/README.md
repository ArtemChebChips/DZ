# Локальный пилот умного добавления

Python 3.12, Apple Silicon, Node 24 и Claude Code с входом Pro/Max.
Платный API не используется. Claude расходует лимит подписки.

## Запуск

Можно запустить `scripts/voice-local/start.command` (остановка Ctrl+C).
Либо из корня репозитория, в двух терминалах:

```sh
.voice-test.local/venv/bin/python scripts/voice-local/server.py
npm run dev:design
```

Открыть http://127.0.0.1:4175/ → Настройки → Для бета-тестеров →
«Текстом или голосом · локальный тест». Для проверки без данных: `?demo=1`.
Кнопка доступна только в dev-сборке. Pages пока не подключён к MacBook.
Сервис слушает только loopback; публичного сервера, туннеля или синхронизации нет.
Не менять bind на 0.0.0.0 без отдельной настройки доступа и HTTPS.

## Установка на новом Mac

```sh
python3.12 -m venv .voice-test.local/venv
.voice-test.local/venv/bin/pip install -r scripts/voice-local/requirements.txt
.voice-test.local/venv/bin/python scripts/voice-local/download.py
```

Нужен ffmpeg в PATH или `.voice-test.local/bin/ffmpeg`.
Установленный `imageio-ffmpeg` содержит бинарник: путь возвращает
`.voice-test.local/venv/bin/python -c 'import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())'`.
Claude ищется в PATH или в установке Claude Desktop. Можно задать `DZ_CLAUDE_BIN`.
Вход выполняется командой Claude Code `auth login --claudeai`.
Токены и записи в репозиторий не добавлять. `.voice-test.local` игнорируется Git.

## Что работает

- Полные предметы и расписание из текущих исходных данных приложения при каждом запросе.
- Черновики нескольких заданий, корректировки текста, предмета и даты, исключение карточек.
- Модель извлекает намерение; код проверяет ответ и рассчитывает сроки.
- Следующая пара учитывает вид, чётность и время. Разные виды без уточнения требуют выбора.
- Дни недели требуют явной даты в карточке. Даты без года тоже требуют уточнения.
- ВУЦ сохраняется заметкой с предметом, как в ручном редакторе.
- Сохранение пакета одним действием только после проверки; ошибка записи оставляет карточки.
- Parakeet загружается при первой записи и остаётся в памяти. Запись до минуты;
  аудио удаляется после обработки. Расшифровку можно исправить до отправки Claude.
- Отмена записи, отмена запроса, запрет параллельной обработки, ограничение размера.
  Отмена браузерного запроса не гарантирует отмену уже начавшегося запроса Claude;
  сервис остаётся занят до завершения или таймаута. Автоматических повторов нет.
