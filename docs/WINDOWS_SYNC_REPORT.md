# Проверка Windows-стенда синхронизации

Версия приложения: **1.24.1**, ветка `codex/agent-sync`.

По уточнённому запросу владельца развёрнут сервер карточек на Windows:
Python/SQLite и Caddy. WSL, голосовые модели и Claude для этой задачи не нужны.
Есть регистрация из приложения с паролем от четырёх символов. Адрес API
подставляется автоматически. Процессы запускаются без консольных окон.

Проверено 1 октября 2026 года:

- 58 тестов клиента и 12 тестов Python-сервера прошли; TypeScript и production-сборка прошли.
- Через интерфейс создан тестовый аккаунт с четырёхсимвольным паролем.
- Карточка из первой копии приложения загрузилась во вторую после входа в тот же аккаунт.
- При остановленном сервере создана ещё одна карточка. После перезагрузки страницы
  без сервера обе карточки остались доступны через сохранённую оболочку PWA.
- После запуска сервера очередь отправилась; вторая копия приложения получила обе карточки.
- После принудительного завершения API runner создал новый процесс; health снова ответил успешно.
- После полной остановки процессов включённая повторная задача Планировщика
  самостоятельно запустила сервер без ручной команды запуска.
- Проверены браузерные размеры 390×844 и 1280×720, вход и выход, запрет запросов
  без авторизации и с чужим Origin. Это не проверка физического iPhone.
- SQLite-копии создаются при запуске и затем ежедневно; база находится вне checkout.

Публичный HTTPS-доступ через Funnel ещё не включён: автоматическая проверка
разрешений потребовала отдельного согласия владельца на конкретный публичный адрес.
Перезагрузка Windows и доступ с физического iPhone не проверены.
Push этой ветки не публикует изменения на GitHub Pages.

Настройка и ограничения: [WINDOWS_SYNC_SETUP.md](WINDOWS_SYNC_SETUP.md).
