# Синхронизация карточек на Windows

После уточнения владельца нужен только аккаунт и хранение карточек на его ПК.
Существующий Python/SQLite-сервер работает напрямую в Windows: для синхронизации
не нужны WSL, модели распознавания и вход Claude. Веб-приложение может обращаться
к обычному HTTPS-адресу без дополнительных программ на телефонах.

Клиент на самом сервере собирается с `VITE_DZ_API_URL=/api` и
`VITE_DZ_SYNC_ONLY=1` и `VITE_DZ_REGISTER=1`: адрес уже настроен, вход требует логин и пароль,
кнопка голосового ввода скрыта. Сервер получает `DZ_SYNC_ONLY=1` и отключает
агентские запросы, сохраняя вход, синхронизацию, выход и backup. Относительный
адрес автоматически использует тот же сервер, с которого открыто приложение.
Для клиента на другом хостинге указывается полный HTTPS-адрес API.

Caddy слушает loopback и отдаёт `dist-design`; `/api/*` проксирует существующий
Python-сервис, не удаляя `/api`. Туннель на ПК предоставляет постоянный HTTPS.
Для режима без VPN на телефоне можно использовать Tailscale Funnel; Serve требует
подключения клиентов к Tailscale. База остаётся на Windows и защищена аккаунтом ДЗ.
Тестовая сборка не заменяет GitHub Pages и не объединяет ветки.

`pythonw scripts/windows-server/run.py <локальный-config.json>` запускает API и
Caddy в фоне, создаёт согласованную SQLite-копию при запуске и затем ежедневно.
Конфигурация содержит `dataDirectory`, `python`, `caddy`, `caddyfile`, `apiPort`,
`webPort`, `allowedOrigins`; личная конфигурация, база и копии хранятся вне checkout.
Запускать от владельца Windows. Задачу Планировщика с повтором при сбое можно
назначить на вход этого пользователя в Windows и повторять каждую минуту:
у работающей задачи повторный запуск пропускается. Процессы API/Caddy
восстанавливаются самим runner при сбое. Это не запуск до входа пользователя;
перезагрузка и физический iPhone проверяются отдельно.

По просьбе владельца регистрация доступна в приложении, пароль — от 4 символов.
Windows-стенд включает `DZ_ALLOW_REGISTRATION=1`; другие установки по умолчанию
сохраняют закрытую регистрацию. Пароли хешируются через scrypt.

При переходе на тестовую ссылку сначала экспортировать JSON из действующего ДЗ,
затем импортировать копию и войти в аккаунт. Записи другого origin сами не появятся.
После статуса «Сохранено на сервере» чистое устройство получает карточки после входа.
Выключенный или спящий ПК временно недоступен: локальные правки ждут восстановления
связи. До удаления приложения убедиться, что очередь пуста и карточки сохранены.
