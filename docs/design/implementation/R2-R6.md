# Завершение доработок R2–R6 — 25 сентября 2026

Финальная версия: 1.23.19. R1 и R3 были завершены ранее (выбранный C + A без верхнего названия, публикация 1.23.16).

## Изменения

- R2, 1.23.17, f3aed33: мобильный нижний padding 26 px вместо 20. В браузере замерено смещение кнопок и подложки ровно на 6 px при неизменном нижнем крае. Геометрия оболочки и safe area не менялась.
- R4, 1.23.18, 8af8251: поверхность каждой пары — настоящая кнопка с названием предмета, видом и временем. Семинар/лаба открывают ДЗ с точным ID; лекция/ВУЦ — заметку с предметом и датой. Вложенные задания доступны отдельно поверх кнопки. Распознавание свайпов допускает новую кнопку и подавляет клик после свайпа.
- R5, 1.23.19, af88eb4: сворачивание за 360 мс через Web Animations API. У последней задачи сворачивается весь день с заголовком и отступом. При быстрых отметках текущая высота строки передаётся группе. Отмена снимает замороженные стили; reduced motion обходит движение. Пустое состояние появляется с коротким затуханием. Запись done сохраняется сразу.

## Проверки R6

- Сборка каждого этапа; финальные 17 тестов правил/хранилища прошли.
- Chromium (Edge) и настольный WebKit: 375/390/430 px, горизонтальный 844×390, компьютер 1440 px; светлая/тёмная темы. Проверены неподвижные шапка/панель при прокрутке и переключениях, отсутствие горизонтального переполнения, мобильный отступ 26 px.
- Лекция → заметка без lessonId/kind; семинар → pn-4; две лабораторные → pn-3 и pn-5. Редактирование вложенного задания и галочка не открывают создание. Проверены Enter, реальные события touch через CDP: горизонтальный свайп, вертикальная прокрутка, короткое нажатие по времени.
- До исправления последняя задача дня давала отдельный скачок следующей группы примерно на 90.6 px. После исправления в Chromium/WebKit измеренный скачок в момент удаления группы — 0 px. Проверены обычная строка, последняя строка дня, длинная запись, нижний край прокрутки и единственная задача; перед удалением остаточная высота/последний сдвиг scrollTop менее 3 px.
- Быстрые завершения нескольких строк, отмена во время/после эффекта, история и возврат, смена вкладки, reduced motion, перезагрузка с сохранённым done. Сроки, точная пара и testBatchId сохраняются. Проверено сообщение об ошибке при отказе записи.
- Календарь с 4/5/6 рядами сохраняет высоту; WebKit: редактор работает при уменьшении viewport до 375×400 и восстановлении. Это имитация доступного пространства, а не системная клавиатура iOS.
- Экспорт JSON содержит исходные сроки и lessonId; повторное чтение проверено в отдельных пустых браузерных контекстах. Данные владельца не использовались. Итоговые снимки обеих тем просмотрены.

Проверка на физическом iPhone, VoiceOver и плавность установленной PWA на устройстве владельца недоступны в этой среде. Настольный WebKit не заменяет эту проверку.
